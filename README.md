# 開箱寶 Unpacky

一個 Windows 小工具：把「壓縮包」和「密碼本」拖進視窗，自動逐個試密碼解壓縮。

## 功能
- **拖放式操作**：壓縮包拖進視窗任何位置即可加入
- **密碼本自動試密碼**：一行一個密碼，自動逐個嘗試
- **三種解壓位置**：目前資料夾 / 個別檔名資料夾 / 個別檔名資料夾+刪除壓縮包
- **免安裝**：內建 7-Zip 引擎（7z.exe），不用另外安裝任何軟體
- **中文密碼、中文檔名都支援**
- **密碼本自動記憶**，下次開啟自動載入
- **即時進度條、可隨時取消**
- **無黑色視窗、可愛圖示**
- **介面語言切換**：繁體中文 / 简体中文 / English（左上角 Language語言 選單，自動記憶）

## 使用方法
1. 下載最新版 zip，解壓到任意資料夾
2. 雙擊 `開箱寶 Unpacky.exe` 開啟（可愛圖示 + 無黑色視窗；或雙擊「建立捷徑.vbs」，在桌面建立帶圖示的捷徑）
3. 把壓縮包拖進視窗（一次可多個）
4. 輸入或拖入密碼本（一行一個密碼，中英文皆可）
5. 選擇解壓位置，按綠色「開始解壓」
6. 右側「各檔狀態」顯示每個檔：✔ 完成（綠）/ ✘ 失敗（紅）

詳細說明請見資料夾內的「開箱寶 Unpacky-使用說明-UserGuide.html」。
